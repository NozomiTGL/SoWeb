# Directorio de Recursos Visuales SoWeb CRM

Esta carpeta contiene las imágenes estáticas y recursos gráficos de la plataforma:

- `img/servicios/`: Logotipos, banners e iconografía de los paquetes de desarrollo web y software que ofrece SoWeb.
- `media/servicios/`: Archivos adjuntos y muestras cargadas dinámicamente desde el panel de administración.
